# Drum Kit

An interactive Drum Kit web application built using HTML, CSS, and JavaScript. Users can play different drum sounds either by pressing the corresponding keyboard keys or by clicking the on-screen drum pads. 
The project demonstrates DOM manipulation, event handling, and audio playback in JavaScript.


Features

- Play drum sounds using keyboard keys (`W`, `A`, `S`, `D`, `J`, `K`, `L`)
- Click on drum pads to play sounds
- Visual button animation on key press
- Responsive and clean user interface
- Random user interaction through keyboard and mouse events
- Built using vanilla JavaScript (no frameworks)

Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- Event Listeners
- Audio API
